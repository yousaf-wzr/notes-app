# 📝 Notes App

A clean and responsive Notes App built with **React** and **Tailwind CSS**.

## ✨ Features

- Add, edit, and delete notes
- Notes persist using **localStorage** (survive page refresh)
- Dark / Light mode toggle (also saved in localStorage)
- Responsive design — works on mobile and desktop
- Timestamps on each note

## 🛠️ Built With

- React (Hooks — useState, useEffect)
- Tailwind CSS
- Vite

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/yousaf-wzr/notes-app.git

# Install dependencies
npm install

# Run the app
npm run dev
```
